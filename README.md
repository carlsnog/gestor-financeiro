# gestor-financeiro
Aplicação que permite ao usuário registrar e acompanhar seus gastos e receitas por meio de mensagens de texto (WhatsApp ou chat-simulador)
* O backend implementará técnicas de PLN para extrair valores, datas e categorias a partir de textos livres, normalizando e agrupando entidades financeiras. 
* O sistema gerará alertas quando limites pré-estabelecidos forem atingidos e exibirá um painel de acompanhamento interativo.
* Como extensão, poderá incluir previsão de gastos e consultas inteligentes baseadas em RAG para justificar padrões de consumo.
